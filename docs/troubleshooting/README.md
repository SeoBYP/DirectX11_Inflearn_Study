# 기술 사례 — 문제 진단 기록

이 저장소를 다시 굴러가게 만드는 과정에서 마주친 문제들의 진단 기록입니다.
각 문서는 **배경 → 설계 → 작업 → 고민한 부분과 선택 → 선택 이유 → 결과(측정값)** 순서로 정리했습니다.

공통 원칙은 하나입니다. **가설은 측정으로 죽인다.** 코드를 읽고 "이게 원인 같다"에서 멈추지 않고, 매번 전후를 비교할 수 있는 수치를 만든 뒤 판정했습니다.

| # | 사례 | 한 줄 요약 |
|---|---|---|
| 01 | [애니메이션이 멈춰 있던 원인이 애니메이션 코드가 아니었던 건](01-blocking-message-loop.md) | 스프라이트가 정지해 `Animator` 를 의심했지만, 원인은 진입점의 블로킹 `GetMessage` 루프였다. 메시지를 주입해 화면이 살아나는 것으로 원인을 확정한 뒤 2줄을 고쳤다. |
| 02 | [빌보드 풀숲의 앞뒤가 뒤집혀 보이는 문제](02-billboard-depth-artifact.md) | "블렌드 상태 누수"와 "깊이 테스트 미동작" 가설을 픽셀 diff로 **둘 다 기각**하고, 깊이를 색으로 출력해 **무더기당 깊이가 하나**뿐인 빌보드 기법의 한계임을 확정했다. |
| 03 | [3년 전 코드를 새 툴체인에서 되살리기](03-build-system.md) | 툴셋 이전(v143→v145) 과정에서 **병렬 빌드에서만 터지는 링크 경합**과 **클린 클론에서만 멈추는 빌드**를 찾아 고쳤다. 둘 다 "내 컴퓨터에서는 되던" 문제였다. |

## 각 사례의 대표 측정값

| 사례 | 측정 | 결과 |
|---|---|---|
| 01 | 창 캡처 8프레임의 픽셀 해시 비교 | 서로 다른 프레임 **1/8 → 4/8** (키프레임 수와 일치) |
| 02 | 상태 명시 전후 픽셀 diff | **0.00%** (14/480000) → 블렌드 누수 가설 기각 |

| 02 | 텍스처 알파 분포 분석 | 알파 통과 픽셀 중 검정 **0.0%** → 텍스처 가설 기각 |
| 03 | 병렬 리빌드 | `LNK1104` **간헐 발생 → 0회** |
| 03 | 클린 클론 재현 | **무한 대기 → 오류 0**, 헤더 68개 재생성 |
